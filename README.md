# Φύλλο ασκήσεων μαθηματικών

Δημιουργεί εκτυπώσιμα φύλλα ασκήσεων για παιδιά του Δημοτικού, με κενά που συμπληρώνει το παιδί:

```
1 + □ = 4
□ + 2 = 7
3 + 3 = □
```

Κάθε σελίδα Α4 χωρίζεται σε 4 ομάδες των 10 ασκήσεων.

## Ρυθμίσεις

- **Γλώσσα:** Ελληνικά (προεπιλογή) ή Αγγλικά.
- **Πράξεις:** πρόσθεση, αφαίρεση, πολλαπλασιασμός, διαίρεση, σε οποιονδήποτε συνδυασμό.
- **Μεγαλύτερος αριθμός:** κανένας αριθμός στο φύλλο, ούτε τα αποτελέσματα, δεν τον ξεπερνά. Αν το παιδί έχει μάθει μέχρι το 5, βάλτε 5.
- **Θέση του κενού:** πρώτος αριθμός, δεύτερος αριθμός ή αποτέλεσμα.
- **Ομάδες:** ανάμεικτες πράξεις ή μία πράξη ανά ομάδα.
- **Επιτρέπεται το 0:** ναι (προεπιλογή) ή όχι.
- **Σελίδα με τις λύσεις:** προαιρετική δεύτερη σελίδα για τον γονιό ή τον δάσκαλο.

Η αφαίρεση δεν βγάζει ποτέ αρνητικό αποτέλεσμα και η διαίρεση βγαίνει πάντα ακριβής. Η σελίδα θυμάται τις τελευταίες ρυθμίσεις.

## Χρήση

1. Ανοίξτε τη σελίδα στον browser.
2. Επιλέξτε ρυθμίσεις και πατήστε **Νέο φύλλο** μέχρι να σας αρέσει.
3. Πατήστε **Εκτύπωση** (ή Ctrl/Cmd + P). Χαρτί Α4, κάθετο, περιθώρια «Κανένα» ή «Προεπιλογή».
